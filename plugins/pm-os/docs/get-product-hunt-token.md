# Get a Product Hunt developer token

1. Sign up or log in at https://www.producthunt.com.
2. Open the API dashboard: https://www.producthunt.com/v2/oauth/applications
3. Add an application. Any name works. For the redirect URL, use `https://localhost`.
4. Open the application and find the **Developer Token**. It does not expire.
5. Copy it. Keep it private. Do not share it or post it anywhere.
6. Save it as `PRODUCT_HUNT_TOKEN` in your shell profile. The `setup` skill shows you how.

Product Hunt asks that the API is not used for commercial purposes without permission. Learning and personal projects are fine.
