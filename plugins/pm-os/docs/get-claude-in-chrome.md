# Set up Claude in Chrome

The `find-connections` skill uses Claude in Chrome so it can read LinkedIn as you, in your own signed-in browser.

1. Install the **Claude in Chrome** extension from the Chrome Web Store and sign in with your Claude account. It needs a paid Claude plan (Pro, Max, Team or Enterprise).
2. Open Chrome and sign in to LinkedIn.
3. Run Claude Code with Chrome enabled: `claude --chrome` (or use the Claude desktop app).
4. Check it works: ask Claude "list my open Chrome tabs".

No Apify account is needed for this skill.

Claude only reads pages. You send every message and connection request yourself.
